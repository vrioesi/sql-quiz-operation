Q1산술연산자

각 직원의 first_name과 연봉(salary × 12)에 보너스를 더한 값을 annual_total로 조회하는 쿼리를 작성하시오.

정답 확인 
SELECT first_name, salary * 12 + bonus AS annual_total
FROM Employees;

결과: 725000, 663000, 784000, 700500, 626500 (영수, 미나, 준호, 지현, 민우 순)

* 가 + 보다 우선순위가 높아 괄호가 필요 없습니다.

Q2비교 + 논리연산자

영업부가 아니면서 급여가 55000 이상인 직원의 first_name, last_name을 조회하는 쿼리를 작성하고, 결과를 쓰시오.

정답 확인 
SELECT first_name, last_name
FROM Employees
WHERE department <> '영업부' AND salary >= 55000;

결과: 미나 이(55000), 준호 박(65000)

>= 는 경계값을 포함하므로 급여가 55000인 미나도 조회됩니다.

Q3LIKE

first_name이 '민'으로 시작하는 정확히 두 글자 이름을 가진 직원을 조회하는 쿼리를 작성하시오.

정답 확인 
SELECT employee_id, first_name, last_name
FROM Employees
WHERE first_name LIKE '민_';

결과: 105, 민우, 정

_ 는 정확히 1글자, % 는 0글자 이상을 대체합니다.

Q4IN + BETWEEN

부서가 영업부 또는 마케팅이면서 보너스가 3000 이상 4500 이하인 직원의 employee_id를 조회하는 쿼리를 작성하고, 결과를 쓰시오.

정답 확인 
SELECT employee_id
FROM Employees
WHERE department IN ('영업부', '마케팅')
  AND bonus BETWEEN 3000 AND 4500;

결과: 102, 104

BETWEEN은 양 끝값을 포함합니다. 보너스가 5000인 101은 범위 밖이라 제외됩니다.

Q5IS NULL

보너스가 NULL인 직원을 찾는 올바른 조건을 고르시오.

① WHERE bonus = NULL
② WHERE bonus IS NULL
③ WHERE bonus <> NULL
④ WHERE bonus == NULL
정답 확인

정답은 ②입니다. NULL은 '알 수 없는 값'이라 =, <> 같은 일반 비교연산자로는 판별할 수 없고 결과가 UNKNOWN이 됩니다. 그래서 IS NULL 또는 IS NOT NULL을 사용해야 합니다.
